# Shreyansh Sachan — portfolio

Multi-page creative developer portfolio — React 19, TypeScript, Tailwind CSS v4, TanStack Router (file-based),
Lucide icons, built with Vite. The hero's "holo folder" is pure CSS 3D (`src/components/portfolio/hero/HoloFolder.tsx`).

```bash
npm install
npm run dev        # local dev server (regenerates src/routeTree.gen.ts)
npm run typecheck  # strict TypeScript
npm run lint       # ESLint
npm test           # Vitest content, filter and game-rule tests
npm run build      # type-check + production build to dist/
npm run preview    # serve the production build
```

## Routes

| URL | File |
|---|---|
| `/` | `src/routes/index.tsx` |
| `/work`, `/work/:slug` | `work.tsx`, `work_.$slug.tsx` |
| `/achievements` | `achievements.tsx` |
| `/blog`, `/blog/:slug` | `blog.tsx`, `blog_.$slug.tsx` |
| `/contact` | `contact.tsx` |

The trailing underscore in `work_` / `blog_` un-nests detail pages from their archive pages while keeping the
`/work/:slug` URL. `src/routeTree.gen.ts` is generated by the router plugin — never edit it by hand.

This is a client-rendered SPA: when deploying, configure the host to serve `index.html` for unknown paths
(e.g. a Netlify `/* /index.html 200` rewrite or Vercel rewrite) so deep links like `/work/sherlock` load.

## Ricochet playground

The homepage game (`src/components/portfolio/RicochetPlayground.tsx`) is a Matter.js 0.20 physics sandbox
drawn on a canvas. Pure rules — scenarios, launch speed, scoring, shot limit — live in `playground-rules.ts`
with tests beside them; edit the `scenarios` array to change or add challenges.

## Project artwork

Each project card has an interactive illustration (`src/components/portfolio/art/`) driven by the pointer,
with a slow autopilot when idle and full `prefers-reduced-motion` support. The method is written up in
[`docs/interactive-project-artwork.md`](docs/interactive-project-artwork.md).

`github-profile/` holds the animated SVG version used on the GitHub profile README; regenerate it with
`node github-profile/generate.mjs`.

## Content

All content lives in `src/components/portfolio/content.ts` and comes from Shreyansh's resume: profile links,
experience, projects (with live demo and GitHub links), achievements, skills and education. The journal holds
reading notes on classic software essays: each credits the author and links to the original, and the summaries
are original writing, not quotes. To add your own post, add an entry to `posts` without `source` and with a
`date`. Project artwork in `ProjectPreview.tsx` is decorative illustration, not screenshots.

The hero's "what I'm into" lists (music, books, movies) find their cover art by title, and songs also get a
30-second iTunes preview clip and Apple Music link: run `npm run covers` after editing them.

## Link previews and SEO

Titles and descriptions for every page live in `src/lib/meta.ts`. The app renders in the browser, but link
scrapers (LinkedIn, WhatsApp, Slack, X) don't run JavaScript, so `npm run build` also writes a static
`index.html` per page with its tags filled in, plus `sitemap.xml` and `robots.txt` (see `prerenderHeads` in
`vite.config.ts`). The share image is `public/og.png`; its source and the command to regenerate it are in
`scripts/og-image.html`.
